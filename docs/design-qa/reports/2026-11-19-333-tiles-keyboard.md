- **Вердикт:** NO_VERIFIED_RULE
- **Колькасць:** RULE 0 · DIFF 0 · OPINION 0 · NOT-VERIFIED 2
- **Ахоп:** PR да [issue #333](https://github.com/kudy-vk/KUDY/issues/333); base `0448c937` (main), head — галіна `zcode/333`, каміт `a197d153`. Змененыя паверхні — блок трох транспартных плітак (`.tiles`, клас `.tile`) у раздзеле «Транспарт» абодвух прадакшн-макетаў «Пра горад»: [about.html](../../design/production/about.html) і [about-257.html](../../design/production/about-257.html). `tile()` у [about-parts.mjs](../../design/production/about-parts.mjs) будзе native `button` (быў `div` з `role="link"`, `tabindex="0"` і толькі pointer-click), `appTile()` у [about-screen.mjs](../../design/production/about-screen.mjs) больш не ставіць лішні `tabindex`; у стылях `.tile` абодвух HTML дададзеныя `text-align: left; cursor: pointer;` (кампенсацыя UA-стайляў кнопкі). Дзеянне, словы і паведамленні дошкі не мяняліся; сама мова змены — даступнасць, не візуал.
- **Крыніцы:** [visual-language.md](../../design/visual-language.md) — адзіны акцэнт для галоўных дзеянняў і фокуса (`color.accent #1d6b4f`, канонавае 3px кольца фокуса); глобальнае правіла `:focus-visible { outline: 3px solid #1d6b4f }` у [kit.css](../../design/production/kit.css) (радкі 91, 133); [exceptions.md](../exceptions.md) не тыкаецца (тэматычных змен няма); рашэнні ўладара ў [brand/decisions.md](../../design/brand/decisions.md) для гэтай паверхні не тыкаюцца (вобраз #254 аб складзе раздзела не пераглядаўся).
- **Асяроддзе:** Linux-хост (CachyOS), Chromium праз Playwright, мокап-старонка з лакальнага сервера репазіторыі, мова be, тэма светлая, вьюпорт 1000×2200. Прылады/TalkBack — не тыкаецца (мокап на HTML, не Android-экран). Артэфакты: `.scratch/dq333/` — `tiles-before.png` / `tiles-after.png` (about.html), `tiles-257-before.png` / `tiles-257-after.png` (about-257.html), `tiles-focus.png` (фокус клавіятурай на плітцы Jakdojade).

## Правераныя правілы канона

1. **Візуальная ідэнтычнасць да/пасля** — элементны здымак блока `.tiles` у абодвух экранах да змены (base `0448c937`) і пасля (`a197d153`): аднолькавыя байтава (sha256 `d8555d61…` ва ўсіх чатырох), літары/колеры/прамежкі без змен — кампенсацыя `text-align: left` нейтралізуе цэнтраванне кнопкі, `cursor: pointer` адпавядае прэцэдэнту `.srow`.
2. **Клавіятура і семантыка** — плітка ёсць native `button` з `role="link"` (прэцэдэнт радоў афіцыйных старонак `.srow` у тым жа файле), Enter і Space актывуюць дзеянне, указальнік працуе як раней; гэта пацвярджаецца тэстом [test/about-tiles-browser.test.mjs](../../../test/about-tiles-browser.test.mjs) на абодвух рэальных шляхах. Фокус клавіятурай малюе канонавае 3px акцэнтнае кольца (`:focus-visible` у kit.css) — здымак `tiles-focus.png`.
3. **Токены** — ніводны колер/шрыфт не мяняўся: `.tile` трымае `var(--muted)`/`var(--ink)`/`.icon` → `var(--accent)`, шрыфт успадкоўваецца праз правіла кнопак `font: inherit` у kit.css; Golos/Alegreya/Caveat ролям не тыкаюцца (тэксты тія ж).
4. **Станы** — новых станаў няма: зменены толькі тэг-носьбіт дзеяння; прынятыя станы раздзела «Транспарт» (#254, #257) не мяняліся.
