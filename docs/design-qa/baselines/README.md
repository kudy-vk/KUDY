# Узоры (baselines) visual:check

Піксельныя ўзоры матрыцы V1 (спец §8.1): светлая тэма × шрыфт 1 / 1.5 × мова
`be`. Адзін файл = адзін слот матрыцы: `<паверхня>@font<маштаб>-<мова>.png`.
Паверхні: чатыры гісторыі карткі гіда праз экран узораў
(`kudy:///dev-specimen?component=guide-card&story=<назва>`, DQ-02/DQ-03),
экран Explore у дзвюх фазах (`explore-a` — без каталога, `explore-b` — з
фікстурным каталогам G23.01) і «Пра горад» (`about-city-list` — раздзел
«Дзе што ў горадзе», згортка «Зоны, станцыі і аэрапорт спісам» адкрытая;
issue #320).

## Як яны знятыя

- Тул: `npm run visual:check -- --update` (DQ-03) — адзіны спосаб змены гэтай
  тэчкі. Ручная праўка або замена файлаў забароненая: узор без прыгоджанага
  запісу паходжання не ўзор.
- Асяроддзе: AVD `kudy-ci` (рэпліка дакладнай каманды
  `.github/workflows/android-e2e.yml`), API 36, swiftshader_indirect, адзін
  эмульятар у сістэме; анімацыі 0; статусбар выключаны ў параўнанні (crop
  верхніх 100 px, DQ-01); дэма-рэжым SystemUI не выкарыстоўваецца.
- Паходжанне першай здымкі: 2026-11-01, змена DQ-03 (issue #913), коміт
  чытання крыніц `9ec83904`, APK dev-кліента SHA-256
  `f7e30d0f8b56c571…` (поўны ў `manifest.json` прагону).
- Парытэт пасля пераключэння вобраза эмулятара на android-35 (#164, рашэнне
  ўладальніка 2026-11-06): госць android-35 google_apis (pixel_5, RAM 4096,
  тул і сцягі ранера) паўтарае ўзоры дакладна — visual:check PASS 12 ·
  DIFF 0 · FAIL 0 (прагон 2026-11-06, APK SHA-256 `8632973f…`, поўны ў
  `manifest.json` прагону `2026-11-06T00-48-49-292Z-local`). Пераздымка
  не патрабавалася; гістарычная здымка 2026-11-01 засталася на API 36.

## Статус

Узоры знятыя рэплікай CI-профілю лакальна; эквівалентнасць «лакальны host ↔
CI runner» не вымераная (DQ-01), таму эталонам лічыцца CI: уручным запуску
workflow артэфакт PNG спампоўваецца і камітуецца праз
`visual:check --update --from <тэчка>`. Ухваляе ўладальнік (DQ-04, issue
#915) — да таго ўзоры маюць статус «пендынг».

## Пераздымка guide-card-long-title — рашэнне ўладара (#353)

2026-11-21 уладар ухваліў пераздымку эталонаў `guide-card-long-title`
(абедзве шрыфт-адзінкі) па правіле рэвалідацыі #353: пасля мержу RN 0.88
([PR 352](https://github.com/kudy-vk/KUDY/pull/352)) рэндэр змяніўся
дэтэрмінавана — прагон пераздымкі вымераў супраць старых эталонаў
21890 px = 0.9048% (font 1) і 11692 px = 0.4833% (font 1.5), дыф-выявы
паказваюць змену пунктаў пераносу загалоўку і рэндэр шестярэнкі dev-меню
(гл. [results/353.md](../../agent-tasks/results/353.md)); upstream шляху
адкату няма. Пераздымка: `visual:check --surface
guide-card-long-title --update` на `d3fe4a6e` (KUDY_E2E_SKIP_INSTALL=1,
dev-client d3fe4a6e на kudy-ci). Поўнаматражную зялёную верыфікацыю матрыцы
пасля пераздымкі пацвярджае наступны рэгулярны E2E-прогон (у гэтай сесіі
транспарт uiautomator дэградаваў — клас #173; усе іншыя слоты не тыкаліся).

## Часовы эталон about-city-list — умова ўладара

Эталон паверхні `about-city-list` — **часовы** (рашэнне ўладара 2026-11-17,
рэзалюцыя пытання 2 справаздачы дызайн-QA
[2026-11-16-about-map-312-a11y.md](../reports/2026-11-16-about-map-312-a11y.md)):
ён папярэдзіць уладарскі кантрольны тэст, заўвагі якога пасля выпраўлення
стануць новым эталонам — «не на заўсёды». Policy «ніколі не абнаўляць
базлайны нячыста» не адмяняецца: гэтыя два файлы не перазапісваюцца іншымі
зменамі, заменіць іх можа толькі новы ўладарскі здымкавы прагон.
