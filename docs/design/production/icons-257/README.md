# Пяць каляровых SVG-іконак для каруселі «Пра горад» (#257)

Крыніца стылю — **апошні набор з пяці медальёнаў, прыняты ўладальнікам 18.11.2026**. Гэта яго намерна спрошчаная вектарная інтэрпрэтацыя: бронзавы кант, натуральны насычаны сіні фон неба (#129CDB → #0575B9), крэмавыя дэталі, тэракотавыя і зялёныя акцэнты. Без блікаў, воблакаў, хваль, дробных дэкаратыўных тэкстур і складаных ценяў.

Файлы (кожны — самастойны SVG 256×256, толькі геаметрычныя элементы, без PNG):

- [airport.svg](airport.svg) — самалёт.
- [gdansk.svg](gdansk.svg) — гістарычныя будынкі Гданьска.
- [map.svg](map.svg) — складзеная карта з маркерам.
- [food.svg](food.svg) — страва пад клошам і сталовыя прыборы.
- [transport.svg](transport.svg) — гарадскі аўтобус спераду.

**Адзіны прынцып:** вонкавы бронзавы медальён, тонкая цёмная акантоўка, мала буйных каляровых формаў, добрая чытэльнасць пры 64 px. Геаметрыя рамкі аднолькавая для ўсіх. Зыходнік для паўторнай генерацыі — [build-257-clean-icons.py](../tools/build-257-clean-icons.py); праверка — [check-257-clean-icons.py](../tools/check-257-clean-icons.py).

[Ранейшая старонка параўнання](../about-257-icons.html) застаецца толькі гістарычным тэстам у [адзіным HTML-каталогу](../../catalog.html). Новыя SVG праглядаюцца **ў самім экране** [«Пра горад» #257](../about-257.html) праз пераключальнік «Іконкі кола» — з сапраўднай інерцыяй, клавіятурай, падсветкай і базавымі медальёнамі `main` для параўнання. У коле чатыры раздзелы; пятая іконка «Карта» запасная. Гэта **кандыдат на дакладны вектарны выгляд**, не канчатковы запіс дызайн-канону і не ўбудаваныя актыўныя/неактыўныя станы. У сапраўднай каруселі цяпер **чатыры раздзелы**; іконка карты — запасная, яна не дадае пяты пункт.

Усю пяцёрку трэба візуальна зацвердзіць уладальнікам перад заменай іконак у вытворчым каталогу, анімацыяй або распрацоўкай у дадатку.
