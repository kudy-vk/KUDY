Прыняты выгляд A: Back злева і вяртанне да актыўнай прагулкі справа. Гэта асобны макет, не production-рэалізацыя.

Уладальнік выбраў A · 22.11.2026. B і C засталіся на дошцы для параўнання, не для production.

Пераключай памер экрана (320/360/390/430 dp), мову, буйны тэкст, стан Run і варыянт. Два тэмы паказваюцца адначасова.

Зацверджаны выгляд A: простая стрэлка Back і заліты круг са слядамі для вяртання да прагулкі. Адкрытае пытанне: дзе размяшчаць дадатковыя дзеянні на вузкім экране з буйным тэкстам.

Усе кнопкі маюць 48×48 dp, назву для экраннага чытальніка і бачны фокус. Пры адсутнай або завершанай прагулцы shortcut знікае; на Run яго няма нават пры актыўнай сесіі.
