# Мабільны экран «Гіды»

[Адкрыць інтэрактыўны макет](prototype.html) у браўзеры. Гэта прапанова для каталога маршрутаў у [#42](https://github.com/kudy-vk/KUDY/issues/42).

У верхняй стужцы — стрэлка назад, знак маршруту з галоўнага меню, назва горада і іконка фільтраў. У картцы — месца для фота 64 × 64, кароткая анатацыя, мовы тэксту і аўдыё і пазнака доступу. Поўнае апісанне адкрываецца з карткі. У фільтрах пакуль зарэзервавана месца пад будучыя катэгорыі, таму паказваюцца ўсе гіды.

На дошцы можна параўнаць светлую і цёмную тэмы, чатыры шырыні, звычайны і буйны тэкст, карткі з фота і без яго, адзін маршрут, доўгі спіс і стан з кэша. Тэставы банер знаходзіцца пад спісам. Калі рэклама не загружаецца, спіс займае вызваленае месца. Размяшчэнне прапанавана паводле ніжняй прывязкі ў [ADS-01](../ADS-01/specimen.html), дзе яна тычыцца галоўнага меню.

У асобнай сесіі параўноўваем гэты макет з [карткамі Run](../RUN-card-states/README.md). Тут картка прадстаўляе маршрут у каталогу, а ў Run — кропку падчас прагулкі. Для ўніфікацыі варта параўнаць загалоўкі, іконкі, фота і ніжнюю рэкламную зону. Рашэнні па банеры і катэгорыях фільтраў застаюцца адкрытымі.

Назва і поўнае апісанне прыкладу ўзятыя з [каталога](../../../../../content/discovery/discovery.json). Фота паказана заглушкай, астатнія карткі і пазнакі моў ды доступу — тэставыя. Макет адкрываецца лакальна з убудаванымі шрыфтамі, іконкамі і здымкамі меню. Праверка макета праведзена ў Chromium. Android і TalkBack — яшчэ не правераныя.
