# Інтэграцыя ў React Native / Expo

Гатовы кампанент — [CityMapMenu.tsx](CityMapMenu.tsx), яго публічныя параметры — `CityMapMenuProps` у гэтым жа файле. У дадатку кампанент сам нічога не збірае: няма кнопкі аўтазборкі, таймера зборкі або прыцягвання пры простым суседстве. Счапленне правяраецца толькі падчас рэальнага руху пасля ўтрымання 300 мс.

Пакет пераўжываецца без капіявання: [адаптар галоўнага меню](../../../../../../components/city-map-menu.tsx) імпартуе гэты renderer і існы экспарт геаметрыі. [Галоўны экран](../../../../../../app/menu.tsx) выконвае пераходы. Кампанент чытае канонавыя токены і `ScaledText` з `components/`, таму яго больш не трэба капіяваць як самадастатковую тэчку. WebView і новыя залежнасці дадатку не патрэбныя.

## Production-кантракт MAP-06, 2026-11-04

Пасля заставы адкрываецца `/menu`. Кароткі націск на `nearby`, `guides`, `discovery` адкрывае адпаведна `/map`, `/city/gdansk/guides`, `/discovery`. `reserve-1` і `kudy` бачныя з лакалізаванай пазнакай «Хутка», але не маюць маршрутаў. Пры вяртанні экран перамантоўвае renderer: раскладка зноў разабраная, без чытання або запісу сховішча. Актыўная прагулка мае асобную іконку вяртання; пераходы не аддаюць каманд Run або аўдыё.

`cityMenuConfig` задае `mapVersion`, стабільныя ID геаметрыі, ключы подпісаў, іконкі, маршруты і пачатковую раскладку. Геаметрыя па ID адпавядае `manifest.json` і яго генераванаму `native-layout.ts`; выявы бяруцца з ранейшага `native-assets.ts`. Production выкарыстоўвае `layout.dragEnabled = false`: перацягванне і зборка застаюцца асобнымі інтэграцыйнымі задачамі MAP-07/MAP-08. Ранейшы інтэрактыўны preview працуе з параметрамі па змаўчанні.

`CityMapMenuProps.items` абмяжоўвае рэндэр зададзенымі ID, вызначае іх accessibility-парадак і дазваляе `disabled` ды іконку. Націск па масцы, кнопцы подпісу і accessibility-актывацыя аддаюць `onSelect` толькі для актыўнага пункта. Без `items` паводзіны preview захоўваюцца: усе экспартаваныя кавалкі актыўныя. `layout` задае вышыню сцэны і пачатковыя пазіцыі ў пікселях крыніцы; `width` мусіць быць дадатнай канечнай колькасцю dp. Змена подпісаў або стану пунктаў не скідае мадэль; змена ID ці раскладкі стварае новую. `sceneLabels` можна не перадаваць: тады дэкаратыўныя вада і ўмацаванні не ствараюць асобных accessibility-кнопак.

Зона карты захоўвае светлую палітру ў абедзвюх тэмах паводле DT-4; навакольны экран чытае тэму АС. Банэр і футэр тут не рэалізаваныя. [Вынікі і межы доказу MAP-06](../../../../../agent-tasks/results/MAP-06.md).

```tsx
import { CityMapMenu } from './menu-map-mobile/native';
import type { PieceId } from './menu-map-mobile/native';

// Назвы, падказку і назвы сцэны падае лакалізацыя экрана.
<CityMapMenu
  width={availableWidth}
  labels={menuLabels}
  hint={dragHint}
  sceneLabels={sceneLabels}
  labelStyle={{ fontFamily: 'GolosText_400Regular' }}
  onSelect={(id: PieceId) => menuFlows[id]()}
/>
```

`menuFlows` — мапа пяці апрацоўшчыкаў у экране аплікацыі. Сюды падключаюцца існыя навігацыйныя флоў. Кампанент не ведае маршрутаў і не перадае раздзелу назву замест ID. Пункт `reserve-1` прызначаецца патрэбнаму флоў хостам. Назвы можна мяняць і перакладаць без страты пазіцый або стану зборкі. Для новай раскладкі перамантуй кампанент праз звычайны React `key`.

Шырыня — сапраўдныя dp даступнай вобласці, вышыня разлічваецца аўтаматычна як `width × 1.125`. Для тэлефонаў выкарыстоўвай 320–430 dp; зыходныя PNG маюць дастаткова пікселяў для гэтай велічыні пры 3×. Не ўключай status bar або safe-area ў шырыню кампанента. Шрыфт падагружае экран: у KUDY яго ўжо забяспечвае `useAppFonts()`.

Пяць дакладных альфа-масак вызначаюць націск; празрыстыя прамавугольнікі выявы не ловяць суседнія раздзелы. Верхняя паласа, вонкавая вада, светлая паласа паміж цэнтральнай і ніжняй ружовай часткамі і ўмацаванні з’яўляюцца разам са сцэнай. Націск па іх дае толькі ўнутраны візуальны водгук і ніколі не выклікае `onSelect`.

Усе пяць раздзелаў даступныя экраннаму чытальніку і да, і пасля зборкі. Зборка не патрэбная для адкрыцця флоў. Мультытач, страта responder і сыход у фон скасоўваюць незавершаны жэст. Пры сыходзе ў фон незавершаная фінальная трансфармацыя завяршаецца без далейшага руху. Анімацыя і таймеры чысцяцца пры дэмантаванні. Resize захоўвае злучаныя групы і перапыняе жэст. Сістэмная налада Reduce Motion улічваецца, `reduceMotion` дазваляе хосту яўна задаць рэжым.

Чорная структурная абводка ўнутры меню-частак замененая цёплым пясочным тонам; цень стаў лягчэйшым і цяплейшым. Тэкст не ўпаяны ў PNG. Для эфекту ператварэння ёсць асобныя `--light.png`, форма якіх дакладна супадае з маскамі кавалкаў.

## Праверка ў KUDY

З кораня рэпазіторыя:

```sh
node --experimental-strip-types --test docs/design/brand/outputs/menu-map-city-only/native/model.test.mjs docs/design/brand/outputs/menu-map-city-only/magnet.test.mjs
node docs/design/brand/outputs/menu-map-city-only/native/verify-component.mjs
npx tsc --noEmit --pretty false
```

Гэтыя тэсты падключаныя таксама да `npm test`. Чыстая мадэль правяраецца асобна ад платформы; native-тэст выклікае сапраўдныя responder-апрацоўшчыкі, робіць чатыры перацягванні, збірае ўсе пяць частак і правярае пяць callback ды клікі па сцэне без callback. Візуальныя эфекты і жэсты не замененыя мокам мадэлі.

`preview-entry.tsx` — асобны экран для праверкі кампанента; ён не замяняе entry point аплікацыі. Metro-зборкі для Android і iOS правераныя. Запуск на прыладзе, кадравая частата, TalkBack і VoiceOver на рэальным тэлефоне патрабуюць асобнай мабільнай прыёмкі; браўзерныя здымкі гэтага не даказваюць.


## Выбранае свячэнне, 2026-10-31

Уладальнік выбраў бурштынавы варыянт 1. Палітра, таймінг і геаметрыя святла вызначаныя ў `amber-light.mjs` і агульныя для native і web. Каляровы сілуэт выкарыстоўвае асобную маску; фільтра brightness/invert і шэрай прамежкавай фазы няма.

Вакол карты праходзяць тры адкрытыя гладкія кубічныя крывыя. Іх светлыя ўчасткі рухаюцца павольна; тонкая сярэдзіна мае шырыню 2,5 пікселя крыніцы, звонку — два слабыя пласты бурштынавага святла. Ніткі не маюць hit target, не запускаюць кадры ў idle/complete, чысцяцца пры адмене эфекту і не прайграваюцца ў Reduced Motion. Адзін цыкл заканчваецца разам з трансфармацыяй, без бясконцага паўтарэння.

Счапленне native адразу фіксуе пазіцыю ў межах магнітнай адлегласці і паказвае светлавы водгук 380 мс. Групы рухаюцца падчас зборкі; цалкам сабраная карта застаецца ў цэнтры і захоўвае націскі раздзелаў.
