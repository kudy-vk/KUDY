# Геаметрыя пяці фрагментаў меню

[Маніфест карты](../menu-map-city-only/manifest.json) задае ID, контуры, каардынаты і стыкі. [Зборшчык](../menu-map-city-only/build.py) атрымлівае маніфест і маскі з адной карты. Экспарт MAP-03 чытае гатовы пакет і выводзіць JSON у stdout. Так можна атрымаць геаметрыю для наступных задач без асобнай копіі контураў.

## Каардынаты і стыкі

Пачатак карты знаходзіцца ў левым верхнім вугле зыходнага PNG, вось X ідзе ўправа, Y уніз. Усе прамавугольнікі паўадкрытыя. Поле `path` — знешні SVG-контур у лакальных каардынатах прамавугольніка. Каб перанесці яго на карту, дадай `x` і `y`. Празрыстасць PNG, у тым ліку ўнутры контуру, вызначае фактычную форму і выкарыстоўваецца пры праверцы зборкі.

`anchor` задаецца ў каардынатах карты. Экспарт вылічвае `anchorSquarePx`, бок найбольшага цэнтраванага квадрата ўнутры маскі. Мінімум 100 пікселяў крыніцы — парог гэтай праверкі. Пры шырыні мабільнага кампанента 320 dp яго маштаб 320/1600 дае квадрат прынамсі 20 dp. Подпіс кампанент размяшчае асобна над фрагментам. Геаметрычная праверка не вымярае памер тэксту і мэту дотыку на экране.

`joints` — пары суседзяў з маніфеста. `port` — сярэдзіна прамежку паміж бліжэйшымі пунктамі спрошчаных контураў у каардынатах карты. `gap` — адлегласць паміж гэтымі пунктамі ў пікселях крыніцы. Экспарт паўторна вылічвае контуры, пары, апорныя пункты і адлегласці з гатовых масак тымі ж функцыямі, што і зборшчык. Парог суседства — 125 пікселяў. Прамежкі вады і сцэны захоўваюцца пры зборцы.

Парог захопу задае `snapDistanceDp` з маніфеста. Пры маштабе `s` dp на піксель крыніцы ён роўны `snapDistanceDp / s` у каардынатах карты. [Мадэль](../menu-map-city-only/native/model.ts) параўноўвае зрухі груп адносна іх зыходных пазіцый. Стык захоўвае арыентацыю і зыходную адлегласць.

## Рэзерв і версія

`reserve-2` — верхняя паласа, `reserve-3` — светлая паласа паміж фрагментамі. Межы прапанаваных зон бачныя ў `reservedZones`. Валідатар правярае, што ў абедзвюх зонах ёсць непразрыстыя пікселі сцэны і няма дзейных фрагментаў. Гэта зарэзерваваныя месцы для будучай працы. Існыя ID, уключаючы `reserve-1`, застаюцца прывязанымі да сваіх масак.

`mapVersion` у экспарце бярэцца з `version` у маніфесце, як і ў [канфігурацыі меню](../../../../../components/city-map-menu.tsx). Для новага фрагмента выкарыстай новы ID, захавай контуры, пачаткі каардынат і стыкі ранейшых фрагментаў і павяліч версію маніфеста. Калі мяняецца зыходная карта ці геаметрыя існых фрагментаў, зафіксуй асобнае рашэнне аб сумяшчальнасці і правер новую зборку да рэлізу.

## Праверка і экспарт

З кораня рэпазіторыя з Python, NumPy і OpenCV:

```sh
python docs/design/brand/outputs/menu-map-city-only/verify.py
python docs/design/brand/outputs/MAP-03/test_geometry.py
python docs/design/brand/outputs/MAP-03/geometry.py > map-geometry.json
```

Першы скрыпт правярае піксельную зборку са слаямі сцэны і адпаведнасць мабільных масак. Другі правярае экспарт і адмоўныя выпадкі. Трэці стварае геаметрычны JSON для лакальнай працы. [Вердыкт па правах](../../../../agent-tasks/results/MAP-02-RIGHTS.md#3-вердыкты-па-асновах-ac3-ac5) абмяжоўвае вытворчае выкарыстанне графікі.
