## Палітыка і межы (чытаць разам са спісам)

- [Палітыка правоў RCIN](https://rcin.org.pl/dlibra/text?id=copyright-law): рэпазіторый сам правярае статус PD, але папярэджвае пра ахоўваныя сучасныя вытворныя і навуковыя/крытычныя выданні public-domain твораў — таму крыніцай бярэцца файл з запісу RCIN, а не старонні скан.
- [Сканы planygdanska.eu](https://planygdanska.eu/en/copyright) — «personal use only»; для production-асетаў не выкарыстоўваць.
- Артыкул W. Długokęcki 2015 ([KHKM 63/2](https://journals.iaepan.pl/khkm/article/view/848)) — CC BY-NC-ND 4.0: толькі тэкставая даследчая спасылка, ілюстрацыі не для мадыфікаванай камерцыйнай карты.
- Калі ў геаметрыі з'явіцца OpenStreetMap — асобна праверыць [ODbL і атрыбуцыю OSM](https://www.openstreetmap.org/copyright); гэта не датычыць старадаўніх гравюр.
