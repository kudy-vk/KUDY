# MAP-02 — вектарная майстар-карта (чарнавік)

[map-master-vector.svg](map-master-vector.svg) — рэдагуемая вектарная копія абранай [map-cutout-v2](../map-cutout-v2.png). Унутры няма растравых выяў: участкі вады і ўмацаванні — асобныя шляхі сваіх пластоў; вуліцы — па адным шляху на злучаную вулічную сетку аднаго колеру ў межах групы раёна (`street-<раён>-NNN`), таму выбар адной вуліцы ў рэдактары хапае ўсю яе сетку; кожнае дрэва або купка дрэў — група `tree-NNN` з некалькіх шляхоў (аснова і блікі). Статус вектарнай версіі — **draft**. [Вынік праверкі публікацыі ілюстрацыі](../../../../../agent-tasks/results/MAP-02-RIGHTS.md).

## Пласты

Пласты ідуць знізу ўверх. Базавыя пласты (вада, умацаванні, зеляніна, раёны) разам цалкам пакрываюць сілуэт. Вуліцы, дрэвы і лініі ляжаць зверху, таму пад імі няма шчылін.

| ID пласта | Што ўнутры |
|---|---|
| `outer-contour` | Вонкавы няпрамавугольны контур — адзін суцэльны шлях цёмнага колеру; ён жа запаўняе субпіксельныя зазоры пад лініямі |
| `water` | Рака, равы і каналы ў трох адценнях |
| `fortifications` | Валы, бастыёны і іх зялёныя схілы |
| `greenery` | Лугі і астравы, абкружаныя вадой |
| `districts` | Шэсць груп: `district-nearby`, `district-guides`, `district-discovery`, `district-reserve-1`, `district-kudy` — пяць частак меню; `district-strips` — светлыя палосы горада па-за меню |
| `streets` | Вуліцы па групах раёнаў; адзін шлях — адна вулічная сетка аднаго колеру |
| `buildings-landmarks` | Пусты: у абранай карце няма будынкаў, прыдумваць іх нельга (рашэнне ўладальніка ў [#109](https://github.com/kudy-vk/KUDY/issues/109), 2026-11-03) |
| `trees` | Кожнае дрэва ці купка дрэў — асобная група `tree-NNN`: аснова і блікі |
| `outlines` | Цёмныя контурныя лініі па групах раёнаў |
| `district-markers` | Пусты паводле таго ж рашэння ўладальніка |

Сістэма каардынат агульная з [manifest.json](../../menu-map-city-only/manifest.json): `viewBox="0 0 1351 1164"`, адна адзінка — адзін піксель зыходнага PNG, арыентацыя не змененая. Групы `district-*` пакрываюць сушу сваіх частак меню і выходзяць за іх толькі на 880–1 280 px — гэта паласа 0,6 px ад штрыха, які закрывае швы. ID частак і маршруты не змяняліся.

## Як паўтарыць экспарт

З кораня рэпазіторыя:

```sh
python docs/design/brand/outputs/MAP-02/vector/export.py
python docs/design/brand/outputs/MAP-02/vector/verify-vector.py
```

Першая каманда стварае SVG і ўсе экспарты: [PNG у поўным памеры](map-master-vector.png), [прэв'ю поўнай карты](preview-full.png), [прэв'ю 240 × 207 px](preview-240.png) і [пяць частак на шырыні тэлефона](preview-phone-pieces.png) (390 CSS px, шчыльнасць 3×). Прэв'ю ляжаць на фоне `color.paper` (`#faf7f2`). Другая каманда правярае структуру, паўтаральнасць, супадзенне з арыгіналам, адсутнасць швоў і межы раёнаў.

Патрабуюцца Python-бібліятэкі з [requirements.txt](requirements.txt) (`python -m pip install -r docs/design/brand/outputs/MAP-02/vector/requirements.txt`), Node.js з npm-залежнасцямі праекта (Playwright) і ўсталяваны Google Chrome. Аднолькавы да байта SVG гарантаваны толькі для версій з `requirements.txt`. Вынікі праверкі запісаныя ў [MAP-02-VECTOR](../../../../../agent-tasks/results/MAP-02-VECTOR.md).

## Як рэдагаваць

Адкрый SVG у Inkscape або іншым вектарным рэдактары: пласты бачныя як слаі. Пасля рэдагавання ўручную не запускай `export.py` — ён перазапіша SVG з PNG. Ручная версія SVG становіцца новай крыніцай. Тады праверка паўтаральнасці ў `verify-vector.py` падае. Гэта чаканы сігнал: абнаві праверку ў тым самым PR.

## Абмежаванні

- Карта перададзеная фіксаванай палітрай з 21 колеру. Плаўныя градыенты і мазкі пэндзля сталі плоскімі плямамі, асабліва на схілах валоў. Колеры ліній адзінкавыя, без цёмнага ядра.
- Масты не вылучаныя ў асобную групу: насціл мастоў застаецца ў суседніх светлых палосах або вуліцах.
- Кантраст вуліц з фонам раёнаў узяты з абранай карты і нізкі: 1,1–1,4 : 1. Пры памеры 240 px вуліцы чытаюцца як фактура, а не як асобныя лініі. Колер вуліц задаецца атрыбутам `fill` на кожнай з шасці груп `streets-*`; уласны колер маюць толькі 5 светлых масткоў у `streets-discovery`. Змена ў SVG уручную ламае праверку паўтаральнасці (гл. вышэй); каб змена перажыла перазборку, яе трэба ўнесці ў `build-vector.py`. Выбар колеру — рашэнне ўладальніка.
