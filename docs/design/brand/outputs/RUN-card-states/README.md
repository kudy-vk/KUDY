# Run: карткі паміж кропкамі

[Адкрыць інтэрактыўны макет](prototype.html). Гэта дызайн-прапанова для пазнейшага ўзгаднення экрана Run. Яна не змяняе дадатак, кантракт кантэнту або рэкламную інтэграцыю.

У макеце можна прайсці паслядоўнасць «паміж кропкамі → прыход да кропкі → гісторыя скончылася → паміж кропкамі». Паміж кропкамі застаецца апошняя адкрытая картка. Пасля аўтатрыгера наступная картка адкрываецца з апісаннем. Стрэлкі і гартанне пераключаюць толькі картку; аўдыё кіруецца адной кнопкай у ніжняй панэлі. Пры недаступным GPS кропку можна выбраць уручную.

У згорнутай панэлі ёсць пераход да поўнага тэксту. Паўразгорнутая картка паказвае кароткае апісанне, прыкметны пераход да транскрыпту і стужку фота. Поўная картка паказвае транскрыпт з павелічэннем шрыфту. Націск на мініяцюру адкрывае фота на ўвесь экран з каруселлю.

Рэкламнае месца паказана ўнізе пад панэллю кіравання. Такую прывязку да нізу ўладальнік выбраў у [макеце ADS-01](../ADS-01/specimen.html) для галоўнага меню; яе прымяненне ў Run тут толькі прапануецца. Рэкламны блок можна выключыць у селектары макета для параўнання.

Паводзіны `inspected` і `playing`, аўтаадкрыццё Half і стан Peek узятыя з [кантракту Run](../../../../11_run_interaction.md). Тэксты і фота ў макеце ілюстрацыйныя. Убудаваныя мініяцюры ўзятыя з брэндавых выяў `02-waterfront.jpg`, `04-atlas.jpg` і `07-found-object.jpg` у [калекцыі mobile-welcome](../mobile-welcome-2026-10-19/art/); яны не з'яўляюцца фота кропак маршруту.

Праверка макета: Chromium, шырыня 320 і 430 px; пераход да наступнай карткі, адкрыццё транскрыпту, захаванне карткі пасля гісторыі і адсутнасць гарызантальнага перапаўнення. Прылада, TalkBack, iOS і зацверджаны візуальны baseline — **NOT-VERIFIED**. Android-зборка і E2E для дызайн-файлаў не патрэбныя паводле `tools/ci/android-e2e-scope.mjs`; scope правяраецца перад push.
