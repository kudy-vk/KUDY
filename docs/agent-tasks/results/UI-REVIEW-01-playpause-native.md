# UI-REVIEW-01 native — кантурныя Play/Pause на Run

Задача [#387](https://github.com/kudy-vk/KUDY/issues/387). База `9f7c8de` (main), галіна `zcode/387`, прадукцыйны каміт `0cb6ef4`. Рашэнне ўладальніка — [варыянт A](https://github.com/kudy-vk/KUDY/issues/98#issuecomment-7070333301) (контурны Lucide Play/Pause без бачных подпісаў), зафіксаванае PR [#388](https://github.com/kudy-vk/KUDY/pull/388); эталон знакаў — [board.html](../../design/brand/outputs/UI-REVIEW-01/board.html) (иконка 24×24, `.word` схаваны, кнопка 48×48 dp). Агароджа скоўпаў: змененыя толькі два знакі кнопак гуку, увесь астатні выгляд Run ([#219](https://github.com/kudy-vk/KUDY/issues/219)) не кранаецца.
