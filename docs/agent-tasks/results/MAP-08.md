## UX-правіла раз'яднання

Раз'яднанне складзенай групы забароненае ў межах наведвання меню — гэта выразнае UX-правіла гэтай задачы, задакументаванае па крытэрыі 4 issue #81, які прадугледжвае «раз'яднанне ці яго забарону з выразным UX-правілам». Запіс уладальніка ад 2026-11-05 у issue #81 вызначае межы наведвання і поўны скід раскладкі пры вяртанні ў меню; расфарміраванне груп ўнутры наведвання там не прадугледжана, таму забарона — найпростае правіла без новых станаў: стык трывалы, у мадэлі няма расфарміравання, `cancel` вяртае незавершанае цяганне, але не разбурае групу («snapped groups never split…»). Поўны скід раскладкі адбываецца толькі пры новым мантажы рэндэрэра — вяртанне ў меню, змена ID ці раскладкі (Production-кантракт MAP-06 у [README](../../design/brand/outputs/menu-map-city-only/native/README.md)).
