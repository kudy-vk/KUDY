## Другі праход: адхіленыя кандыдаты RULE

- 48 dp не аформлены як RULE: [палітыка QA](../../agent-rules/design-qa.md) называе мэтавую 48 dp меркаваннем да рашэння ўладальніка (design-QA spec §12). Замер на дампе (52×50 dp) і стыль-тэсты — факты, не канон; крытэрый задачи выкананы, канон не пашыраны.
- Колер іконкі — `palette.colorAccent` праз існыя токены тэмы, новых колераў няма (canon §10 — правілы змены канона не кранутыя): RULE-кандыдат зняты, токен-канфармнасць пацверджаная тэстамі палітр.
- Мяжа і фон кнопкі панэлі (`borderColor: colorLine` у стылі `barControl`) не новае рашэнне — стыль не змяніў межы/фону, змененае толькі дзіця (тэкст → знак): не знаходка.
