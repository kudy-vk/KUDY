## Што высветлена

Знаходка патрабавала пры рэбейзе PR #140 консалідацыі двух прагонераў у адну
каманду `e2e:android:local`, інакш Windows-шлях #137 ператварыўся б у
канчатковы NOT-VERIFIED. Рэбейз гэта выканаў: коміт abe8c91 (#140,
2026-11-05) перапісаў `tools/ci/android-e2e-local.mjs` у агульны ўваход з
дыспетчарызацыяй па платформе — на win32 выконваецца шлях #124 (дыск D:,
коды выхаду 0/1/64/75/86), на астатніх хастах — дэлегаванне ў
`tools/e2e-android/run-local.mjs` з празрыстым argv і вяртаннем exit-кода
(0/1/2/3/4). Усе пяць файлаў-канфліктаў з знаходкі ўзгодненыя яшчэ #140:
`package.json`, `docs/agent-rules/android-e2e-local.md`,
`docs/human-actions.md`, `tools/ci/android-e2e-scope.mjs`,
`tools/ci/e2e-workflows.test.mjs` (даследавана на клоне 2026-11-10).

Застаўся дакументны дрыфт: загаловак `run-local.mjs` трымаў састарэлы сказ
з дакансалідацыйнага стану («The Windows host path is issue #124; here the
runner reports NOT-VERIFIED instead of half-running»), які супярэчыў яго ж
радку 5 («delegates here on non-Windows hosts and runs #124's Windows path
on win32») і рэальнаму wiring-у.
