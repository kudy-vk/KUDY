## Што зроблена

- `test/agent-tasks-links.test.mjs` — перад сканам адносных спасылак тэкст праходзіць pre-pass `blankQuotedLinks` (ідыёма counts-guard `stripCapturedOutput`): fence-радок адкрывае блок, «голы» закрывальны радок яго закрывае, змесціва fence і inline-code spans бланкаюцца з захаваннем нумароў радкоў — хіт дагэтуль называе рэальны радок.
- Root-relative href (пачынаецца з `/`) выведзены са скану: `path.resolve` чытае яго як filesystem-absolute, то бок праверка існавання адносна results-каталога для такога href няслушная.
- Тры новыя фіксчуры-аховы: цытаваная спасылка ў fence праходзіць, а рэальная зламаная пасля fence дагэтуль ловіцца на сваім радку; inline-code span праходзіць (цытаваная і рэальная на адным радку); root-relative праходзіць.
- Гэты results-док сам даганяе правіла: у ім ёсць fence з цытаванай спасылкай на няісны файл — старая ахова б роніла walk на гэтым радку, новая праходзіць:

```sh
echo "цытаваная спасылка ў fence: [missing](missing-report.md)"
```

## Па крытэрах issue #290

1. **Ахова выдаляе fenced-блокі і inline-code перад сканам; цытаваная спасылка ў fence больш не роніць walk** — фіксчуры «a relative link quoted inside a fenced block passes the walk» і «a relative link inside an inline-code span passes the walk»; рэальны walk па `docs/agent-tasks/results/` зялёны.
2. **Негатыўная фіксчура ізалявала правіла** — fence-фікчура трымае рэальную зламаную спасылку пасля fence (`{ line: 4, href: 'missing-report.md' }`), inline-фікчура мешае цытаваную і рэальную на адным радку (`missing-too.md` ловіцца, `missing.md` не), root-relative — асобная фікчура; старая фікчура wrong-depth ловіць як раней.
3. **Guard suite зялёны; npm test — без фейлаў** — `node --test test/agent-tasks-links.test.mjs` 6/6 pass; поўны `npm test` двойчы на `c1f766e`: 3124 тэстаў, 3090 pass, **0 fail**, 33 skipped, 1 cancelled — гэта `grant-core.test.ts` (60s таймаўт пад нагружаным хостам, вядомы клас [#341](https://github.com/kudy-vk/KUDY/issues/341)/[#333](https://github.com/kudy-vk/KUDY/issues/333)); standalone той тэст 20/20 pass за 19.8с.
