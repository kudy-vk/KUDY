# Публікацыя ілюстрацыі меню KUDY

Па выніках праверкі ад 9 лістапада 2026 г. для публікацыі існай згенераванай ілюстрацыі меню KUDY не патрабуецца асобны дазвол або ліцэнзія. Выснова ахоплівае [майстар-ілюстрацыю і пяць фрагментаў меню](../../design/brand/outputs/menu-map-city-only/README.md), правераныя ў гэтай версіі.
