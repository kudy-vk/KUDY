# Падборкі, водгукі і ўкраінская (G15, G16)

Спецыфікацыя — [20](../../20_discovery_and_feedback.md), тэхнічны кантракт — [21](../../architecture/21_discovery_feedback_architecture.md). Атамарныя заданні хвалі выкананыя. Адкрытымі застаюцца эпікі G15 (аўтарскі падбор месцаў, падборак і гідаў) і G16 (непублічныя ацэнкі і справаздача аўтара); іх аб'ём і крытэрыі — у адпаведных GitHub Issues.

Агульныя файлы кантрактаў, архітэктуры і бэклога змяняюцца паслядоўна. Пазнакі `agent:ready` і `prio:*` ставіць толькі аператар.
