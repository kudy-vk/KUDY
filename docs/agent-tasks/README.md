## Як перадаць заданне

> Выканай толькі `docs/agent-tasks/<тэчка>/<ID>.md`. Прачытай яго і пазначаныя крыніцы, правер залежнасці. Вынік і доказы запішы паводле файла. Не выконвай суседнія задачы.

Асноўны бэклог: [16](../16_delivery_backlog.md). Прынятыя правілы і прапановы: [15](../15_guide_decisions.md). Схема кампанентаў, даных і паслядоўнасцей — [18](../architecture/18_component_blueprint.md).
