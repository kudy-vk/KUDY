# Даследчая бібліятэка і пошук гісторый G19

Спецыфікацыя: [25](../../25_content_research.md). План для выканаўцаў: [2026-10-01-content-research](../../superpowers/plans/2026-10-01-content-research.md). Бацькоўскі эпік: #456.
