## Constraints and security boundaries

- Static trusted colors only; no new external inputs, network calls, permissions,
  secrets, persisted data or irreversible actions.
- Gradient is decorative, ignores touches and is hidden from accessibility.
- DT-4 light map/markers and DT-6 light splash remain enforced.
- `color.note` has no replacement in the approved mockup: retain its existing
  canonical value and verify the new foreground against it.
- Preserve unrelated uncommitted human-action entries. Do not include them in the PR.
- Use the installed SVG implementation rather than adding a gradient dependency.
