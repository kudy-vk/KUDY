# Спасылка каталога аднаўляе выбраны прагляд (T03, issue #481)

Кананічны каталог (`docs/design/catalog.html`) запісвае ў фрагмент URL ключ зарэгістраванага прагляду: выбар другой укладкі змяняе спасылку, перазагрузка і новы кантэкст браўзера адкрываюць тую ж укладку, стары фрагмент без укладкі і пашкоджанае кадаванне адкрываюць першы прагляд бяспечна, а перастаноўка ўкладак у `catalog.md` не пераносіць мэту ўжо створанай спасылкі. Node-тэст звярае фрагмент з рэальным рэестрам, Chromium-тэст праходзіць праз сапраўдную старонку і iframe; на адкатзе кода старонкі ўсе пяць браўзерных праверак падаюць.

```bash
node --test --test-reporter=dot test/design-catalog.test.mjs test/design-catalog-browser.test.mjs
```
